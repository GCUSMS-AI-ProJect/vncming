SVG icons from https://github.com/lucide-icons/lucide (retrieved 2026-10-13).
Stroke adapted to VNCMing accent #a44d14. ISC / MIT notices in LICENSE.

`toolbar-transfer.svg` is the VNCMing toolbar icon. `upload.svg` and `download.svg`
use a lighter stroke and rounded tray. FLTK 1.3 uses `toolbar-transfer.png`, generated
from the SVG with `/usr/bin/python3 scripts/render-toolbar-icon.py`.
