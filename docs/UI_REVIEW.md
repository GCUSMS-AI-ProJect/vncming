# VNCMing 界面审查

审查日期：2026-10-14。依据当前 GTK / 原生界面代码、真实界面预览和 Apple Human Interface Guidelines。以下保留审查依据和建议；核心交互与布局已按方案实施。

TypeSafe 的模型发现接口返回 HTTP 451，本次未获得 Jev 评估；结论来自本地审查。此状态不能用于判断 API Key 是否有效。

## 已实施

- 精简主界面品牌元素与操作列，缩小删除入口；新增删除确认、右键编辑和明确的“最近保存”标记。
- 窗口打开方式、远程分辨率使用互斥选择；保留服务器分辨率选项；全屏动态模式会清除内核旧的固定分辨率默认值。
- 编辑连接时就地显示输入错误，证书及控制设置按需展开。
- 上传、下载分别放在对应文件栏；按钮随选择与目标目录状态启用，重连操作随连接状态显示。
- 路径操作减弱边框，新建文件夹移入更多菜单，较窄文件栏隐藏修改时间。
- 任务行提供取消与重试，批量操作收进菜单，无任务时收起表格。
- 远控工具栏增加设备地址，保留独立区域与文件传输图标；连接失败与重试入口采用中文。

验证覆盖删除取消与确认、设置到启动参数、认证、搜索下拉、上传下载、实际鼠标点击取消与重试、重连及失败状态、全屏工具栏与鼠标映射。截图使用模拟端点。

## 结论

功能基本完整，主要问题是常驻次要操作过多、状态与操作没有充分联动，以及连接设置存在相互冲突的选项。建议先改交互和层级，再微调外观。

采用苹果界面的克制、对齐、分组和渐进展示原则，同时保留 Ubuntu 窗口按钮和菜单习惯。无需增加毛玻璃、侧边栏或装饰动画；少量设备没有必要增加导航层级。

保留既有要求：文件传输入口只以图标显示在独立远控工具栏，不覆盖远程画面，不进入设备操作列；连接图标仅显示器、新建仅加号；空白输入框的占位提示在失焦时显示。

## 主界面

| 位置 / 控件 | 判断 | 推荐处理 |
| --- | --- | --- |
| 标题栏与 Ubuntu 窗口控制 | 保留 | 保持系统位置与行为，不换成仿 macOS 红黄绿按钮。 |
| 文件 / 查看 / 帮助 | 保留、收紧 | 保持标题栏下方的现有位置；菜单容纳低频功能，不继续添加常驻栏。 |
| 地址栏左侧应用 Logo | 可移除 | 标题和应用菜单已表达身份；移除这一处重复品牌元素。 |
| IP 地址标签与输入框 | 调整文案 | 输入框同时接受主机名和名称搜索，标签改为“地址”，空白失焦显示“输入地址或搜索连接”。 |
| 搜索下拉 | 保留 | 名称为主、地址为辅；选中后填入地址，下一步才连接。保持键盘与鼠标一致。 |
| 顶部连接按钮 | 保留主操作 | 一个橙色主按钮；空白地址时禁用，连接处理中显示状态并阻止重复启动。 |
| 我的连接 + 数量 | 保留、减弱 | 适度减小标题，数量使用次要文字；避免装饰性胶囊过多。 |
| 新建 + | 保留 | 放列表标题右侧，采用中性按钮；空列表的“新建连接”仅在空状态显示，不算重复常驻入口。 |
| 名称 / IP 地址表头 | 保留 | 当设备增加时便于扫描；“操作”表头可去掉，按钮含义已明确。 |
| 行内连接 | 保留 | 提供无需先选中设备的快捷操作；使用中性色，仅顶部连接突出。 |
| 行内删除 | 调整优先级 | 用户已要求此入口，可保留小垃圾桶按钮；不必与连接同宽。删除前确认并写明设备名称，或实现可靠撤销。 |
| 双击编辑 | 补充可发现入口 | 保持双击；增加右键“编辑连接”，并在行提示中说明双击编辑，不必新增一列大按钮。 |
| 最近徽标 | 改名或移除 | 当前按保存时间排序，标记应为“最近保存”；不能让人误以为最近连接。 |
| 连接列表行高和留白 | 收紧 | 当前约 80px 的行偏高，可向 56–64px 调整，保持文字与图标居中对齐。 |
| 大量圆角框与暖色底 | 适度减弱 | 保持一层内容容器，减少按钮和标签套框；橙色用于主操作、焦点与选中状态。 |

## 连接编辑与设置

| 位置 / 控件 | 判断 | 推荐处理 |
| --- | --- | --- |
| 名称 / 地址 | 保留 | 名称非必填、地址必填；名称留空仍使用地址。输入错误就地提示，减少叠加弹窗。 |
| 用户名 / 密码 | 保留、分组 | 归入“认证”，注明按服务器要求填写；不要把 VNC 密码和 SSH 密码混为一个凭证。 |
| 密码显示图标 | 保留 | 单个眼睛图标，明确显示 / 隐藏提示，保持输入框尺寸不变。 |
| 证书主机名不匹配选项 | 放入高级设置 | 技术性强、低频，默认折叠；按当前功能继续限制到具体地址，不扩大证书豁免范围。 |
| 取消 / 保存 | 保留 | 保存为唯一主操作，取消为次要操作；保持主窗口居中的模态对话框。 |
| 全屏 / 最大化两个复选框 | 合并选择 | 使用“打开方式：普通窗口 / 最大化 / 全屏”，避免同时勾选的含糊状态。 |
| 固定分辨率 / 随窗口调整 | 合并选择 | 使用“远程分辨率：固定 1920×1080 / 随窗口调整”。当前固定与随窗口都勾选，即使后者实际不生效仍容易误解。 |
| 画面铺满窗口 | 保留、独立解释 | 明确这是本地缩放，与远端分辨率设置分开；需兼顾比例失真与用户既有铺满偏好。 |
| 仅查看 / 允许共享 | 放入高级设置 | 归入“控制与共享”，保留功能，降低初次使用时的选择数量。 |

## 已连接界面与错误提示

| 位置 / 控件 | 判断 | 推荐处理 |
| --- | --- | --- |
| 独立顶部工具栏 | 保留 | 不占用远程桌面内容；保留现有 44px 高度，统一内边距和图标尺寸。 |
| 已连接 + 绿点 | 调整信息 | 增加设备名或地址，让多窗口时能够明确操作对象；不要额外重复大标题。 |
| 文件传输图标 | 保留 | 右侧图标按钮与悬停提示；普通 / 全屏位置一致，不把图标悬浮在远程画面上。 |
| F8 菜单 | 保留 | 承载选项、全屏、连接信息等低频功能；常用入口和键盘菜单可并存。 |
| 连接等待与取消 | 保留、进一步统一 | 后续可把等待状态放在连接按钮附近，取消只在等待期间出现；当前单个等待窗可继续使用。 |
| 错误与超时 | 保留单个居中弹窗 | 标题明确“连接失败”，正文包含设备及可操作的原因；所有原生错误和重试文案统一中文，避免不同流程语言不一致。 |

## 文件传输

| 位置 / 控件 | 判断 | 推荐处理 |
| --- | --- | --- |
| 标题与连接状态 | 保留 | 标题“文件传输”，左侧状态，右侧连接相关动作；状态不要被上传选择错误长期覆盖。 |
| 连接设备按钮 | 按状态变更 | 未连接“连接”，连接中禁用并显示进度，已连接的低频“重新连接”可放菜单；不要始终显示同一个“连接设备”。 |
| 通用说明句 | 移除常驻 | “本机与远程设备之间传输文件和文件夹”可移入首次使用空状态。 |
| 上传 / 下载 | 保留、调整位置 | 上传贴近本机栏，下载贴近远程栏，使源文件位置明确；只在对应列表有选中项目且目标目录可用时启用。 |
| 上传橙色、下载白色 | 调整 | 两种操作同级，采用相同中性样式；不要永久暗示上传更重要。高亮可随当前选中的源列表变化。 |
| 本机 / 远程标题与地址 | 保留 | 维持左右对应，设备名为主、地址为辅；本机旁“Ubuntu”可去掉，系统名称无需常驻。 |
| 两侧路径栏 | 保留 | 长路径可通过焦点编辑完整路径；普通状态可采用路径导航，避免大量按钮挤压路径空间。 |
| 上级目录图标 | 保留 | 与路径栏组合、保持固定点击区域，根目录时禁用。 |
| 刷新图标 | 保留、减弱 | 与上级目录成组，不为每个图标增加过重的大边框。 |
| 新建文件夹图标 | 保留低频入口 | 可放各栏“更多”菜单，避免两侧共六个同等视觉重量的方框。 |
| 两栏大小与修改时间 | 保留 | 名称优先分配宽度，时间为次要文字；窗口变窄时先折叠修改时间列。 |
| 重试失败 | 按状态显示 | 有失败任务才出现；优先提供失败任务行内重试。 |
| 取消选中 | 调整位置 | 放进行中的任务行，减少必须先选中任务再取消的步骤。 |
| 取消全部 | 放入更多菜单 | 全局中断不是每次传输都需要的操作；没有可取消任务时禁用。 |
| 清除已结束 | 减弱 | 作为小文字按钮或任务菜单项，仅有结束任务时启用。 |
| 传输任务大表格 | 按需展开 | 无任务时只保留一行简洁空状态；产生任务后展开，不固定占用大块空间。 |
| 大小 / 速度字段 | 分状态显示 | 传输中显示速度及进度，结束显示大小和结果，避免完成任务留下空速度占位。 |
| 独立 SSH 登录与主机指纹 | 保留 | 明确与 VNC 认证不同；指纹确认是关键步骤，不为追求简洁省略。 |

## 推荐布局

主界面：

```text
VNCMing                                      Ubuntu 窗口按钮
文件  查看  帮助
地址  [ 输入地址或搜索连接                  ] [连接]
我的连接 · 3                                 [+ 新建]
名称                  地址                   快捷操作
显示器 设备名称       IP / 主机名             [连接] [垃圾桶]
```

文件传输：

```text
连接状态                 文件传输             [连接 / 更多]
本机                       │ 远程设备 · 地址
[路径] [上级] [刷新] […]     │ [路径] [上级] [刷新] […]
[上传]                     │ [下载]
文件列表                   │ 文件列表
────────────────────────────────────────────────────────
传输任务 · 2                                      [更多]
名称            方向       进度 / 结果        [取消 / 重试]
```

## 实施顺序

1. 修正行为：删除确认或撤销、上传下载随选中状态启用、任务操作随状态启用、分辨率选项互斥。
2. 精简层级：移除重复 Logo 与说明句、收起证书等高级设置、任务操作移入行内与更多菜单。
3. 统一视觉：紧凑列表、路径栏按钮分组、主次按钮颜色、原生与 GTK 错误文案。

优先优化这些实际交互，再考虑细微动画、阴影等外观。当前不需要推翻整体主题。
