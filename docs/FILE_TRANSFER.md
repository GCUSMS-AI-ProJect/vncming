# 文件传输

文件传输可从已连接界面的顶部工具栏、主界面的“文件 → 文件传输…”或远控窗口的
F8 菜单打开。独立窗口左侧是本机，右侧是远程设备，下方是任务队列；先在两侧
打开目标目录，再选中文件或文件夹，点击“上传”或“下载”。也可以从 Ubuntu
文件管理器拖入右侧列表上传。支持多选、子目录及空目录、同名跳过/保留两份/覆盖、
取消和失败重试；悬停任务行可查看完整源路径、目标目录和错误原因。

此功能使用 SSH/SFTP：远程设备需开启 SSH 并提供 SFTP 服务，默认端口 22，
与 VNC 的端口独立。首次使用输入 SSH 用户名和密码，也支持 SSH 密钥/Agent。
SSH 密码独立保存在系统钥匙环；首次连接核对主机指纹，已记录指纹变化时拒绝连接。
远控断开不会自动取消文件传输，关闭文件窗口会询问是否取消未完成任务。

当前版本的重试从头传输，不支持断点续传或暂停；不跟随符号链接，不复制特殊文件，
文件夹传输不承诺保留所有者、权限和修改时间。覆盖通过完整临时文件发布；SFTP
服务器若不支持原子覆盖扩展，将报告失败并保留原文件。文件传输 SVG 图标采用 Lucide，
来源及 ISC/MIT 许可证位于 `assets/transfer/`。运行依赖包含 `python3-paramiko`。

已连接界面的顶部工具栏提供“文件传输”按钮，与远程画面分区显示，不覆盖远程
桌面。普通窗口和全屏均可使用。设备操作列表仅保留连接、删除。更新客户端后，
现有远控连接需重连。
