# VNCMing v1.3.6

本版更新连接管理、文件传输与身份验证界面，并完善语言即时切换。

## 更新内容

- 使用浅色奶白界面和新的浅杏色／珊瑚橙应用图标，修复系统应用列表的旧图标缓存。
- 按钮默认无可见边框，悬停时显示淡灰边框，保持尺寸不变；原生弹窗按钮同步样式。
- 支持跟随系统、简体中文和 English。选择后主界面、打开的设置弹窗与文件传输窗口即时切换，语言偏好自动保存。
- 优化远程工具栏的分辨率选择器和文件传输图标。
- 文件浏览增加返回刚才目录的操作；保持异步目录读取和传输队列。
- 改善连接按钮状态、凭据保存和自动 SSH 登录的交互。

## 安装

适用于 Ubuntu 22.04 / GNOME 42 的 X11 桌面，amd64 架构。

下载 `vncming_1.3.6_amd64.deb` 和对应的 `.sha256` 文件：

```bash
sha256sum -c vncming_1.3.6_amd64.deb.sha256
sudo apt install ./vncming_1.3.6_amd64.deb
```

安装后从应用列表打开 VNCMing。文件传输需要远端启用 SSH/SFTP。
密码保存在系统钥匙环；发布附件不包含个人连接配置或密码。
